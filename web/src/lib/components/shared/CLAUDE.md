# Shared components

Generic, feature-agnostic UI primitives with no domain knowledge of their own — safe to import
from any feature folder.

| File | Purpose |
|---|---|
| `AsyncState.svelte` | Shared loading/error shell so route pages don't each re-implement the "Loading…" + error-box choreography. |
| `Modal.svelte` | The one modal shell (HOLODEX-215): backdrop, surface, rise motion, focus trap and focus return, and stack-aware Escape/backdrop dismissal (topmost modal only; ignored while `busy`). Sizes `sm`/`md`/`lg`/`media`, align `top`/`center`. Callers own the panel's inside (padding, title via `titleId`, body, buttons). See `docs/design/shared-modal-handoff.md`. |
| `ConfirmDialog.svelte` | Destructive confirm dialog, rendered on `Modal.svelte` (size `sm`; Modal owns the trap, Esc/backdrop cancel and focus return; initial focus is the checked radio, else Cancel). The panel is capped at `max-h-[80vh]` and only the body scrolls (HOLODEX-417) — the overlay is `fixed`, so an unbounded panel put Save/Cancel below the viewport with nothing to scroll once a body (`SourceEditModal`) ran to paragraph length. Omit `onconfirm` (and `confirmLabel`) for a report-only state with no confirm button — the F77 flip dialog's "Checking…" and refused states — where `cancelLabel` ("Close") is the only action. |
| `ExpandableText.svelte` | Line-clamped long text with a chevron expand/collapse toggle (the `CompletenessPanel` chevron idiom applied to prose); used for Media Overview, Person bio, and Film description. **Long prose is this component, no exceptions** — bio, overview, description, comments, and whatever comes next all render muted `text-sm leading-relaxed` with the chevron, for owner and visitor alike. It deliberately has no styling props (`tone` was removed in HOLODEX-365 once it turned out only one of three call sites set it): a knob makes "one look for prose" opt-in per page, and a page that needs a different look is a design question, not a prop. Only `lines` (4 / 5) is configurable, because that is a layout fit. |
| `LoadMoreButton.svelte` | The paged-list "Load more (N left)" control (F80): a centred `btn-ghost`, "Loading…" and disabled in flight, gone once nothing is left, plus an always-mounted polite live region for the per-page announcement. Every paged list uses it (HOLODEX-589): the Tags Chips view with `lib/pagedList.svelte.ts`, and the owner queues. Every other library list scrolls the whole list instead (`VirtualRows`, HOLODEX-601/604). Knobs: `noun` ("3 videos left"), `disabled` (held while a sibling list loads), `class` (the row's spacing). Never inline another copy. |
| `VirtualRows.svelte` | The whole-list scroll's grid body (HOLODEX-601, `docs/design/entity-list-virtual-scroll-handoff.md`): rows of `lanes` entries between two spacers, over a `lib/sparseList.svelte.ts` list and a `lib/windowVirtualizer.svelte.ts` window virtualizer. The caller passes the `entry` and `placeholder` snippets (the placeholder must be exactly as tall as the entry: the row-height contract), the row's classes (gap, and the same gap as bottom padding) and the retry row's `noun`. Each entry sits in a `[data-index]` list item, which is the roving Tab stop and carries `aria-setsize`/`aria-posinset`. A failed page gets one retry row on its first whole grid row. Its twin for Table view is `sort/ListTable`'s `window` mode. People (List, Poster), Studios, Films and the Tags Posters view use it directly, and every video grid through `video/VirtualVideoGrid` (HOLODEX-604). |
| `ScrollPositionChip.svelte` | "412 of 1,512" beside the scrollbar while a whole-list scroll moves (HOLODEX-601), fading a second after it stops (the fade is `.scroll-position-chip` in app.css). Decorative (`aria-hidden`), hidden below `sm`, and drawn only when the list is longer than the view. |
| `Switch.svelte` | The small `role="switch"` on/off control (pill track, sliding dot, text label; accent when on). Extracted at its second use (F75's Always shuffle, after `EntityImageSlot`'s Halo) so the two can't drift. |
| `HotkeySheet.svelte` | The `?` keyboard-shortcuts sheet (F62): a derived *This page* group from the hotkey registry (`lib/actions/hotkey.svelte.ts`) plus a static *Navigation* group; rendered on `Modal.svelte` (size `sm`, `data-hotkey-sheet`, `returnFocus` off when a row launches); Page rows are launchers (close, then `focus()`→`click()` the bound button). Two columns past six rows, never scrolls. |
